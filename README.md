# Bittu Badmash

A quick, desi lane-runner where you play a naughty kid dodging Mummy's flying chappals and belans.

## ▶ Play in your browser

**[Play Bittu Badmash](https://bhuwanyu.github.io/Bittu_Badmash_Game/)**

https://bhuwanyu.github.io/Bittu_Badmash_Game/

- Best played on desktop.
- Click inside the game so it picks up your input.
- About 30 MB loads on first play, so give it a few seconds.

Built with Unity (WebGL) and hosted on GitHub Pages.
